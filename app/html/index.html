Кластер Kubernetes в Yandex Cloud

Страница отдаётся контейнером nginx, развёрнутым в кластере. Образ собран из Dockerfile в этом репозитории и загружен в реестр Yandex Container Registry.

Среда
Yandex Cloud, Kubernetes на виртуальных машинах
Узлы
Управляющая машина и две рабочие в зоне ru-central1-a
Мониторинг
Prometheus, Grafana, Alertmanager, node-exporter
Версия образа
загружается
Сборка и публикация образа выполняются в GitHub Actions при коммите в основную ветку и при создании тега.
